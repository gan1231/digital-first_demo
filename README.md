# Говийн ирээдүй сан — тэтгэлгийн бүртгэлийн систем

Дорноговь аймгийн Засаг даргын Тамгын газар, Боловсролын газар хамтран олгох
сургалтын төлбөрийн тэтгэлгийн онлайн бүртгэл.

**Хоёр төрөл**, тус бүр өөрийн бүрдүүлэх материал, 100 онооны шалгуур,
квоттой. Нэг хүн нэг л төрөлд өргөдөл гаргана.

Бүртгэл нь **«ТЭТГЭЛЭГ ГОРИЛОГЧИЙН АНКЕТ»** цаасан загварын дагуу явна: зочин
`/register` дээр анкетаа бүтнээр нь бөглөхөд 1.10-д бичсэн **цахим шуудангийн
хаяг нь нэвтрэх нэр** болж, формын төгсгөлд нууц үг асууна. Илгээхэд хэрэглэгч,
өргөдөл хоёр нэг transaction-д үүсээд `/apply` дээр боловсрол, эссэ, материал,
илгээх алхмууд үлдэнэ.

Анкет нь цаасан загварын 1.1–1.12, 2, 3 хэсгээс гадна журмын 2.1-д заасан
**батлан даагчийн мэдээллийг** (1.13) авна.

| Төрөл | Хамрах хүрээ | Квот |
|---|---|---|
| `GRADUATE` | 12 дугаар анги төгсөгч (ЭЕШ 620+, голч 80+) | 50 |
| `STUDENT` | Их, дээд сургуулийн оюутан (GPA 3.2+) | 30 |

Шаардлага, бүрдүүлэх материал, эрэмбийн дүрэм нь **«Сургалтын төлбөрийн
тэтгэлэг үзүүлэх нийтлэг журам» (2026 оны төсөл)**-ыг дагана.

## Технологи

| Давхарга | Сонголт |
|---|---|
| Web | Next.js 15 (App Router), TypeScript, Tailwind v4 |
| DB | PostgreSQL 17 + Prisma |
| Файл | MinIO (S3-нийцтэй, өөрийн сервер дээр) |

## Локал ажиллуулах

Урьдчилсан нөхцөл: Node 20+, PostgreSQL 17 (локалд ажиллаж байгаа).

```bash
npm install
```

`.env.example`-г хуулж `.env` болгоод `DATABASE_URL`-аа тохируулна. Дараа нь:

```bash
npx prisma db push
npm run db:seed
npm run dev
```

`http://localhost:3000` дээр нээгдэнэ.

## Сонгон шалгаруулалтын шалгуур

**12 дугаар анги төгсөгч — 100 оноо**

| Шалгуур | Оноо | Эх сурвалж |
|---|---|---|
| Мэргэжлийн нийцэл (сумын хүний нөөцийн хэрэгцээ) | 25 | комисс |
| Элсэлтийн шалгалтын дундаж оноо | 30 | автомат (ЭЕШ / 800) |
| Бүрэн дунд боловсролын үнэлгээний дундаж | 15 | автомат (голч / 100) |
| Нийгмийн оролцоо, манлайлал | 10 | комисс |
| Эссэний үнэлгээ | 10 | комисс |
| Ярилцлагын үнэлгээ | 10 | комисс |

**2, 3 дугаар курсийн оюутан — 100 оноо**

| Шалгуур | Оноо | Эх сурвалж |
|---|---|---|
| Мэргэжлийн нийцэл (сумын хүний нөөцийн хэрэгцээ) | 25 | комисс |
| Голч дүн (GPA) | 30 | автомат (GPA / 4.0) |
| Нийгмийн оролцоо, манлайлал | 10 | комисс |
| Суралцахуйн тодорхойлолт | 10 | комисс |
| Эссэний үнэлгээ | 10 | комисс |
| Ярилцлагын үнэлгээ | 15 | комисс |

Шалгуур, материалын жагсаалт хоёулаа **DB хүснэгт** (`ScoringCriterion`,
`DocumentRequirement`) тул журам өөрчлөгдөхөд `prisma/seed.ts`-г засаад
`npm run db:seed` ажиллуулахад хангалттай — код хөндөхгүй. Seed нь нийт оноо
100 болохыг шалгаж, хуучирсан мөрүүдийг устгана. Зарлалыг **(жил, төрөл)**-өөр
тааруулдаг тул нэр өөрчлөгдөхөд давхар мөр үүсэхгүй.

Автомат оноог комисс баримттай тулгаж үзээд гараар засаж болно — засварласан
тохиолдолд «гараар засварласан» гэж тэмдэглэгдэнэ. Шалгуур бүрд **тайлбар
заавал** бичигдэнэ, эс тэгвээс үнэлгээ баталгаажихгүй.

Эцсийн оноо нь баталгаажсан үнэлгээнүүдийн дундаж. Тэнцвэл **журмын 4.4**-ийн
дагуу эхлээд зорилтот бүлгийн суралцагч, дараа нь ЭЕШ/GPA өндөртэй нь дээгүүр
орно. `/reviewer/ranking` дээр «Зорилтот бүлэг» багана, квотын тасалбар зураас
харагдаж, CSV татагдана.

## Материалын шаардлага

`DocumentRequirement` хүснэгт нь эх сурвалж болдог. Нүүр хуудасны жагсаалт,
анкетын хавсралтын хэсэг, комиссын бүрдэл шалгах check-list гурав энэ нэг
хүснэгтээс уншина — админ шаардлага өөрчлөхөд гурвуулаа шинэчлэгдэнэ.

## Эссэ

Эссэг системд шууд бичнэ. Тод, налуу, доогуур/дундуур зураас, цэгт болон
дугаартай жагсаалт, ишлэл гэсэн энгийн формат дэмжинэ. Гадны сангаас
хамаарахгүй — `contentEditable` дээр суурилсан.

Гаралт нь HTML тул **хадгалахын өмнө болон харуулахын өмнө** `sanitize-html`-ээр
цэвэрлэгдэнэ (`src/lib/essay.ts`). Зөвшөөрсөн шошго 10, **атрибут огт
зөвшөөрөхгүй** — `onerror`, `javascript:` мэтийн гарц хаагдана. Word, вэбээс
хуулсан бичвэрийг зөвхөн энгийн текстээр авна.

Үгийн тоог сервер тал шошгыг хассаны дараа бодож `essayWordCount`-д
хадгална — эдитэр дээрх тоолуур үүнтэй тохирно.

## Файл хадгалалт

Бүх файл MinIO дээр private bucket-д хадгалагдана. Хуулах нь browser-оос шууд
presigned PUT-аар (сервер дундуур явахгүй), үзэх нь эрх шалгасны дараа 10 минут
хүчинтэй presigned GET-ээр. Хадгалалтын түлхүүр:

```
applications/{applicationId}/{requirementCode}/{uuid}.{ext}
```

Эх файлын нэр DB-д тусад нь хадгалагдана — кирилл үсэг, давхардал, path
traversal-аас сэргийлнэ.

`S3_ENDPOINT` (дотоод) ба `S3_PUBLIC_ENDPOINT` (браузерын хандах) хоёрыг заавал
тусад нь тохируулна. Presigned URL нь хостоо гарын үсэгт оруулдаг тул дотоод
хаягаар presign хийвэл браузер хандаж чадахгүй.

## Deploy

```bash
docker compose --env-file .env up -d
```

`minio-init` контейнер нь bucket, хязгаарлагдмал эрхтэй service account, CORS-ыг
нэг удаа тохируулна. MinIO console (9001) нь зөвхөн localhost руу bind хийгдсэн —
хандахдаа SSH tunnel ашиглана.
